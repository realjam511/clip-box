# クリップ置き場 (Clip Box) - iPhone用クリップボード保存 PWA

コピーしたテキストが上書きで消えてしまう問題を解決する、iPhone・スマホ向けのクリップボード保存専用 PWA（Progressive Web App）です。

## 公開URL
- **PWA Webアプリ**: [https://realjam511.github.io/clip-box/](https://realjam511.github.io/clip-box/)

## 主な特徴
1. **貼り付けて保存**: 「貼り付けて保存」ボタンをタップするだけでクリップボードから自動保存（手入力メモ追加も完備）。
2. **重要メモのピン留め**: 上部にピン留め（📌）固定。
3. **高速インクリメンタル検索**: キーワード部分一致検索＆ハイライト。
4. **完全オンデバイス・プライバシー**: データは端末内の `localStorage` にのみ保存され、外部サーバー通信は一切行いません。
5. **JSONバックアップ・復元**: 全データのダウンロード・取り込み・一括コピーに対応。
6. **iOS ショートカット連携**: `?text=...` のURLパラメータ経由で共有シートから1タップ保存可能。
7. **PWA オフライン稼働**: Service Worker キャッシュにより地下鉄や機内モードでも即起動。

## iPhone ホーム画面への追加手順
1. iPhone の Safari で上記公開URLを開く
2. 画面下部中央の **共有ボタン（四角から上矢印）** をタップ
3. メニューをスクロールし、**「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ
5. ホーム画面に専用アプリアイコン「クリップ置き場」が配置され、ネイティブアプリ感覚で全画面起動できます。

## iOS ショートカット作成レシピ
Safari 等の共有シートから1タップで保存するショートカットの作り方：
1. iPhone の「ショートカット」アプリを開き、「＋」で新規作成
2. 右上の詳細（ｉマーク等）を開き、**「共有シートに表示」** をONにする
3. 「アクションを追加」で **「URL」** を検索・追加し、URLに以下を設定：
   `https://realjam511.github.io/clip-box/?text=ショートカットの入力`
   （※「ショートカットの入力」は変数としてタップ指定）
4. アクション **「URLを開く」** を追加
5. ショートカット名を「クリップ置き場に保存」にして完了！

これで、Web記事やSNSで選択したテキストの共有メニューから瞬時に保存できます。
