# クリップ置き場 (Clip Box) — iPhone用クリップボード保存 PWA

コピーしたテキストが上書きで消えてしまう問題を解決する、iPhone・スマートフォン向けのクリップボード保存専用 PWA（Progressive Web App）です。

## 📱 iPhone ホーム画面への追加手順（アプリ化）

1. iPhone の **Safari** で上記公開URL（`https://realjam511.github.io/clip-box/`）を開きます。
2. 画面下部中央の **共有ボタン（四角形から上向きの矢印が出ているアイコン）** をタップします。
3. 表示されたメニューを少し下にスクロールし、**「ホーム画面に追加」** をタップします。
4. アイコン名「クリップ置き場」が表示されるので、右上の **「追加」** をタップします。
5. ホーム画面に専用アイコンが配置されます。タップするとアドレスバーやツールバーのない**全画面（ネイティブアプリ感覚）**で起動します。

## ⚡ iOS ショートカット連携レシピ（共有シートから1タップ保存）

Safari で見ているWebページやメモ帳、SNS等で選択したテキストを、共有メニューから「クリップ置き場」に直接1タップで保存するショートカットの作成手順です。

### ショートカットの作成方法（所要時間：1分）
1. iPhone の標準アプリ **「ショートカット」** を起動します。
2. 右上の **「＋」** をタップして新規ショートカットを作成します。
3. 画面下の検索バーまたは上部のメニューから、以下の2つのアクションを追加します：
   - **アクション1**: **「URL」**
     - URL欄に以下を入力します：
       `https://realjam511.github.io/clip-box/?text=`
     - 末尾に続けて、キーボード上の候補から **「ショートカットの入力」** 変数を選択・配置します。
     - ※ショートカットの設定（画面上部の詳細・ｉアイコン）で **「共有シートに表示」** をONにし、受け取る対象を「テキスト」や「URL」にしておきます。
   - **アクション2**: **「URLを開く」**
     - アクション1で生成したURLを開くように設定します。
4. ショートカットの名称を **「クリップ置き場に保存」** に変更し、好みのアイコン（クリップやノート）を選んで「完了」を押します。

### 使い方
- ブラウザやSNSで文章を選択 ➔ **「共有...」** ➔ リスト内の **「クリップ置き場に保存」** をタップ。
- 自動的に「クリップ置き場」が開き、テキストが瞬時に保存されます。

## 🛠️ 主な機能一覧

| 機能 | 説明 |
| :--- | :--- |
| **貼り付けて保存** | 「貼り付けて保存」ボタンを1タップするだけでクリップボードから自動読み取り＆保存。 |
| **手入力メモ追加** | 「＋ 手入力で新しいメモを書く」ボタンから、キーボード入力でのメモ保存も可能。 |
| **ピン留め固定** | 重要なメモはピン（📌）留めして画面最上部に常時固定。 |
| **再コピー・編集** | 各クリップをワンタップで再コピー、または鉛筆アイコンから文章修正可能。 |
| **削除 ＆ 取り消し（Undo）** | 誤って削除しても、画面下の「元に戻す」トーストから即時復元可能。 |
| **インクリメンタル検索** | 検索窓に文字を入れると部分一致でリアルタイム絞り込み＆キーワード黄色ハイライト。 |
| **URL自動検知** | テキスト内にURLが含まれる場合、「🔗 リンクを開く」ピルが自動生成されワンタップで遷移。 |
| **完全オンデバイス** | データは端末内の `localStorage` にのみ保存。外部サーバー通信は一切行わず、プライバシー安全。 |
| **JSONバックアップ・復元** | 設定モーダルから全データをJSONファイルとしてダウンロード・読み込み・一括コピー可能。 |
| **自己診断パネル** | 設定モーダル内に Clipboard API、ストレージ容量、Service Worker、起動モード等の診断情報を常備。 |
| **完全オフライン対応** | Service Worker によるキャッシュにより、電波の届かない地下鉄や機内モードでも即起動。 |
